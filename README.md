# 🛒 E-Commerce Sales Analysis

An Excel-based data analysis project focused on understanding e-commerce sales performance, customer purchasing patterns, product performance, and overall business trends.

## 📌 Project Overview

This project analyzes e-commerce sales data using **Microsoft Excel** to transform raw transactional data into meaningful business insights.

The analysis focuses on identifying sales trends, evaluating product performance, understanding customer behavior, and supporting data-driven business decisions.

## 🎯 Objectives

* Analyze overall sales performance
* Identify top-performing products and categories
* Understand customer purchasing patterns
* Analyze sales trends over time
* Identify areas contributing to revenue
* Create clear and interactive Excel-based analysis
* Present business insights in an easy-to-understand format

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* Data Cleaning
* Data Analysis
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Visualization
* Dashboard Design

## 📊 Analysis Performed

The project includes analysis of:

* Sales and revenue
* Product performance
* Category-wise performance
* Customer purchasing behavior
* Time-based sales trends
* Key performance indicators (KPIs)

## 📈 Key Skills Demonstrated
